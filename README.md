# CTF de ciberseguridad

Preparación para los concursos de captura de la bandera (CTF), de tipo *jeopardy* y de ataque y defensa: cómo reconocer cada tipo de reto, las herramientas y técnicas de cada categoría (criptografía, web, reversa, explotación de binarios, forense y OSINT) y la estrategia de un equipo durante la prueba.

**Ver en línea:** https://aaramirez.github.io/ctf/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
